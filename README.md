Program Konversi Mata Uang Sederhana (Go)

Proyek ini dibuat untuk memenuhi tugas praktikum pengelolaan versi program menggunakan **Git** dan **GitHub**. Program ini mengonversi nominal mata uang Rupiah (IDR) ke berbagai mata uang asing dengan kurs tetap, serta dilengkapi dengan fitur pemotongan biaya administrasi dan validasi input.

Deskripsi Project
Program ini adalah aplikasi CLI (*Command Line Interface*) menggunakan Go (Golang) untuk menghitung penukaran mata uang Rupiah (IDR) ke:
1. **Dollar Amerika Serikat (USD)** - Kurs: Rp 15.800
2. **Euro (EUR)** - Kurs: Rp 17.200
3. **Yen Jepang (JPY)** - Kurs: Rp 105
4. **Ringgit Malaysia (MYR)** - Kurs: Rp 3.550

---

Fitur-Fitur Program
1. **Konversi Multi-Mata Uang**: Konversi instan ke 4 mata uang asing sekaligus.
2. **Validasi Input**: Menolak input bukan angka dan angka bernilai nol atau negatif.
3. **Fitur Biaya Admin 1%**: Potongan otomatis sebesar 1% dari uang yang ditukarkan dengan menampilkan rincian nominal kotor dan bersih.
